# Student Records Manager

A command-line student management application built using Python.

## Features
- Add student records
- Display all students
- Show students who passed
- Search for students by name
- Update student scores
- Delete student records
- Save and load records using JSON
- Validate user input

## Technologies Used
- Python 3
- JSON
- File handling
- pathlib

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `py student_manager.py`

5. Follow the menu instructions.

## Data Storage

Student records are stored in a `students.json` file. Records are loaded when the application starts and saved when changes are made.
